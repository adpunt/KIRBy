# Where each noise method came from

Claude's records, not reviewed by the author. They are judgements and search results, not
measured results; do not copy a bucket or a "none found" into the thesis without checking it.

- `METHOD_PROVENANCE.md` (2026-10-08): one line per noise detector and cleanup, with file and line,
  in four buckets: faithful to a published method / published method with a stated change / no
  precedent found / provenance unclear (AI-written report, ported code, or a citation that does not
  describe the code).
- `LITERATURE_SEARCH_2026-10-08.md`: what the 2026-10-08 literature search found for each method
  family, whether it has been used on molecular data before, and which methods were not searched.
