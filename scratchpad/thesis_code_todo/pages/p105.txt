5.1.2      The adaptive hybrid representation
The task of selecting the best features from a set of representations and combining
them is not simple. How do you measure what features are “best”? Are these features
“best” relative to the representation they came from or to the whole pool of features?
Should you select more features from representations that seem to have more signal
to begin with, or take a set number of features from every representation? How many
base representations should you select features from? How many features should you
select? When scoring potential combinations of features, what type of evaluator should
you use?
   In a dream world, there would be a single answer to each one of these questions
that applies to every dataset. Unfortunately we live in reality, and as I discovered,
the answer to every single one of these questions is “depends on the data.” The task
of selecting the best features then became a search space optimization challenge. The
question actually became for a given prediction task, defined by the dataset, prediction
target, and model, what is the best methodology for selecting features? The hybrid
search does not output just a list of features, rather it outputs an ideal search con-
