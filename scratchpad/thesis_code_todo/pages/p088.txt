4.3     Results

4.3.1     Flaws in standard representations
General-purpose representations are built to span a broad range of chemical domains.
When your dataset covers only a small region of the chemical space, a lot of the features
within these generalized representations become irrelevant, describing chemistry which
is absent from the data at hand. Pairwise comparisons of these representations rely on
these irrelevant features.


Constant and near-constant features

To investigate similarity estimation, we first look at a simple measure: how many
features vary within a dataset. A single dataset often contains a set of relatively similar
molecules. Many features within a generalized representation contain information that
describes all, or almost all, of the molecules in the set, failing to capture the variation
between them. We define a constant feature to be one that takes a single value in every
molecule of a dataset and a near-constant feature to be one that carries the same value
in at least 95% of the molecules. We counted constant and near-constant features from
a set of representations (described in Table 5.12) across hERG Ki , Caco-2, LogD, QM9,
MDR1–MDCK efflux, human liver microsome (HLM) clearance, rat liver microsome
(RLM) clearance and the Lhasa hERG blocker training set. MDR1–MDCK efflux and
the two clearance datasets come from Biogen [137]. HLM clearance and the Lhasa
hERG set are not in Table 5.12; their base representations are those with counts in
