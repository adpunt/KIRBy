6.4     Conclusions
Chapter 4 found that distance in standard representations barely rises with label differ-
ence. On the six small-molecule datasets, we found that distance in a hybrid built for
distance tracks label differences more closely than in the single representation. Predic-
tion from nearest neighbors improves on all six, both at the setting fixed before the run
and with the setting picked again. In addition, the neighbors retrieved in the hybrid
have closer labels. On LogD, Caco-2, hERG Ki and hERG blocking, each model’s first
hybrid also predicts cliff molecules better than its best single representation.
   Weighting features by importance does part of the same work without any selec-
tion. On LogD it lets the single representation track label differences better than the
unweighted hybrid. The hybrid’s distance does, however, track prediction error worse
on hERG blocking, and except on QM9 and Buchwald–Hartwig its kept features carry
no more label information than principal components of the same size.
