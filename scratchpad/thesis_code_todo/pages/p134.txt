One fold fewer

A second check repeats each outer fold’s search with one more fold removed from its
training samples, for each of the other four folds. The held-out fold is the same and
the two searches differ by one fold of training samples. Each search, however, picks its
own budget, so the two hybrids can differ in width as well.


Feature reduction at the same width

On regression datasets, every method receives B features from all base representations
joined, fitted on the fold’s training samples. The methods are the two best hybrids
at budget B from the fold’s search, mRMR [175], recursive feature elimination [178]
and B random features. mRMR ranks features by mutual information and stops at
200 features for run time. It consequently has no result on any small-molecule dataset,
where every budget is 250 features or more. Recursive elimination fits a 50-tree random
forest of depth 5 and removes 10% of the features at each step. Each of the dataset’s
two downstream models scores every method, and only the features differ.


Internal evaluator

One search per outer fold is run for each evaluator setting. The matched evaluator
belongs to the downstream model’s family, while a near-family evaluator pairs tree
models with each other, the SVM with a Gaussian process, and the DNN with a
narrower DNN. A far-family evaluator pairs tree models with an SVM, the SVM with
LightGBM, and the DNN with k-nearest neighbors. A fourth setting scores the DNN
with a wider DNN, and a fifth searches the dataset’s own internal evaluators (Table 5.6).
Each setting’s search picks its own budget, and the number of features can thus differ
between settings. The SVM’s near-family evaluator ran before the Gaussian-process
correction of 8 October 2026 on every dataset.
