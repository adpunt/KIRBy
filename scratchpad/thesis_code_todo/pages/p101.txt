   A representation that avoids these flaws would need five properties (Table 4.5). Its
features would be chosen for the task, using only each fold’s training labels. It would
be compact, dropping features that do not vary or do not matter, with the number
kept searched rather than fixed. It would draw on several representations, since each
misses information the others capture; plain concatenation does this but is not compact
(Chapter 5, “Combining representations”). It would work both as a model input and
as a space for similarity. Finally, it would be traceable: each chosen feature leads back
to its representation and can be read chemically wherever the base feature can.
   Feature selection cannot fix every flaw. Molecules identical in every base repre-
sentation stay identical in the hybrid, and a selected hashed bit still merges every
substructure folded into it. Selection also needs enough labeled molecules to estimate
which features matter.
   Chapter 5 builds the adaptive hybrid representation and asks how to select its
features for a given prediction task (Section 5.2.2).
