   The global pool sizes each representation’s offer with squared weights r̃k2 , as shares
of a pool of 2B candidate features. Each offer is capped at the representation’s width
and holds only features scoring above 0. The same importance method is fitted once
on the joined offers, and the hybrid keeps the top B features that score above 0. Each
