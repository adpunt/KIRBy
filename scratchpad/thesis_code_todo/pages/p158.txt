5.3.5    Features chosen across separate sites
Feature selection can run where data cannot be pooled. When each site holds one
family of representations, one selection over all families beats the best family and the
best single representation, on Caco-2 and LogD with both models (Table 5.26). On
LogD with the SVM, for example, it is well ahead of the best family, and the best
single representation is further behind. Selecting at each site with an even share of
the budget does as well as one selection over all families on every dataset and model,
although it can build a different number of features. Each site can therefore select on
its own and send only feature indices.
