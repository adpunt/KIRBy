\section{Methods: experimental setup}
% [notes moved to thesis_notes_moved.md]
% CODE INPUT
This section sets out how the experiments in this chapter were run. It covers the 16 datasets of six domains and their folds, the base representations offered to the search, and the downstream models and metric used on each dataset. It also describes the comparators, controls and ablations that test the hybrid's gain, and three further studies on transfer between datasets, antibody mutational scans and data held at separate sites.

% CODE INPUT
Every experiment follows the same protocol. Each of the 16 datasets is split into five outer folds, with no group split across folds. One analysis of the antibody expression scan uses three outer folds of unequal size instead, as stated where that result is reported. The hybrid search sees only the training samples of each outer fold, and the selected features are then rebuilt on those samples and applied unchanged to the held-out samples.

% CODE INPUT
The hybrid is compared against the best single base representation used at its full number of features, which asks whether the hybrid beats what a user would otherwise run. This comparator is chosen from the search's own single-representation scores on the training samples of the outer fold, then refit on those samples and scored on the same held-out samples as the hybrid. Because it is chosen separately for each downstream model and each fold, it can be a different representation in each fold. Choosing it on the held-out samples would give it an advantage that the hybrid does not get. The hybrid is held to its budget of base features, to which any augmentation features are added. The comparator has no budget and is therefore often many times wider than the hybrid. Both widths are recorded for every fold, since a difference between the two scores is partly a difference in width as well as in method. The main quantity per fold is the hybrid's score minus that of the best single representation, signed so that a positive value always means the hybrid scored better (for RMSE the sign is flipped). For each dataset and downstream model, we report the per-fold scores of the hybrid and of every single representation, and their spread across the five folds.

% CODE INPUT
Chapter~\ref{chap:similarity} reuses this protocol with noise added to the training labels of each outer fold, while the held-out labels stay clean.

The hybrid experiments use 16 datasets from six domains, summarized in Table~\ref{tab:datasets}. These are five small-molecule ADME and toxicity endpoints, one quantum-chemical property, two reaction-yield sets, four antibody sets, two nucleotide-sequence tasks and two cancer classification tasks from TCGA. Every score in this chapter is computed on held-out folds that keep each group whole, with the groups of each dataset chosen to match what an unseen sample means in its field. The curation of each dataset, with counts before and after each step, is given in Appendix~\ref{app:datasets}, and the representations each dataset uses are listed in Table~\ref{tab:dataset_reps}.

% TODO: review, needs manual review
Different biological domains have established different conventions for what constitutes a good prediction, and applying a single metric everywhere would misrepresent performance in at least some of them. We therefore assign each task a primary metric matched to its domain. These metrics are RMSE for molecular property prediction, Spearman rank correlation for antibody regression and developability, and AUROC for binary classification, including antibody classification and tumor subtype. Multiclass classification uses weighted F1, drug-target affinity uses the concordance index, and reaction yield uses $R^2$.
% TODO: REVIEW MODIFICATION
Different biological domains have established different conventions for what constitutes a good prediction, and applying a single metric everywhere would misrepresent performance in at least some of them. The metric of each dataset is given in Table~\ref{tab:datasets}, and the reason for each choice is given in ``Models and metrics''.

% TODO: review, needs manual review
No random splits are used in this chapter. Random splitting inflates performance estimates for molecular data by placing structurally similar compounds on both sides of the train/test boundary \citep{Yang2019, Wallach2018}. In deep mutational scanning data, position-level leakage likewise allows models to memorize site-specific effects rather than learning generalizable sequence-fitness relationships \citep{Notin2023, Vieira2026}. Splits therefore follow the conventions of each domain and use five-fold group $k$-fold cross-validation throughout.
% TODO: REVIEW MODIFICATION
No split is random (Chapter~\ref{chap:background}, ``Evaluation methodology''). Regression datasets use five-fold group $k$-fold cross-validation, and classification datasets use five-fold stratified group $k$-fold cross-validation.

\paragraph{Pre-processing.} The pre-processing steps shared across datasets are listed below, and the per-dataset steps with the counts after each step are given in Appendix~\ref{app:datasets}.
\begin{enumerate}[leftmargin=*]
    \item Every molecule is parsed with RDKit \citep{rdkit}, and molecules that fail to parse are dropped. On hERG $K_i$, LogD and Caco-2 the structures are also standardized by keeping the largest fragment, neutralizing charges, choosing the canonical tautomer and removing molecules that contain a metal.
    \item Repeat measurements of one molecule are merged into their median on hERG $K_i$, LogD and Caco-2. On hERG $K_i$, molecules whose repeat measurements have a standard deviation above 1.0 p$K_i$ units are removed, since $K_i$ values combined from different sources are a known source of large label noise \citep{landrum2024}.
    \item Duplicate molecules are removed by InChIKey on the six small-molecule datasets, keeping the first occurrence.
    \item LogD and Caco-2 labels are clipped at the 1st and 99th percentiles of the dataset.
    \item Two datasets are subsampled once with a fixed seed. From QM9, 10,000 of the 129,428 parsable molecules are kept, and from the trastuzumab set, 5,000 of the 524,346 variants are drawn in proportion to each combination of label and number of mutations.
\end{enumerate}

\paragraph{Splitting rules.} Four rules hold for every dataset. First, folds are formed as in Chapter~\ref{chap:background}, ``Evaluation methodology'', so no group is split, regression datasets use group $k$-fold and classification datasets use stratified group $k$-fold. Second, there are five outer folds, and the stratified folds use a fixed seed. Third, no split is ever random. The handling of a dataset with fewer groups than folds is stated in Chapter~\ref{chap:background}, ``Evaluation methodology'', but every dataset here has at least five groups, so all outer splits have five folds. Fourth, on a given dataset every representation, model and hybrid is scored on the same five folds.

% TODO: review, needs manual review
The hybrid construction step uses a nested internal train/validation split within each training fold to score representations for feature allocation. This internal split is group-aware and takes the first fold of a grouped five-fold split with the same grouping variable as the outer cross-validation. This prevents the internal evaluator from seeing related samples on both sides of its split.
% TODO: REVIEW MODIFICATION
Inside each outer training fold, the search scores representations on one group-aware internal split, which is described in ``From base representations to a hybrid''.

% TODO: review, needs manual review
\paragraph{Groups by domain.} The small-molecule and QM9 datasets are grouped by Bemis--Murcko scaffold, as defined in Chapter~\ref{chap:background}, ``Evaluation methodology''. In this chapter the scaffold keeps stereochemistry, and all acyclic molecules share one empty scaffold, which on QM9 forms the largest group and holds 1,041 of the 9,978 molecules. The two Biogen datasets (rat liver microsome clearance and MDR1--MDCK efflux) have 1.2 and 1.1 molecules per scaffold, respectively (the $n$ and group columns of Table~\ref{tab:datasets}). Holding out a scaffold on these datasets is therefore close to holding out single molecules. Chapter~\ref{chap:robustness} used a different scaffold key and different curation for its versions of LogD, Caco-2, hERG $K_i$ and QM9, and Appendix~\ref{app:datasets} lists the differences.

% TODO: review, needs manual review
The reaction datasets are Buchwald--Hartwig C--N couplings run on high-throughput plates, in which aryl halide, ligand, base and additive are varied. They are grouped by additive, following the out-of-sample tests of \citet{Ahneman2018}, so each held-out fold contains four or five additives the model never saw in training. The two sets are not independent, since they share 3,955 reactions (Appendix~\ref{app:datasets}).

% TODO: review, needs manual review
On the Koenig deep mutational scan of the anti-vascular endothelial growth factor (VEGF) antibody G6, every variant carries one mutation. Variants are grouped by the position of that mutation modulo 5, as in ProteinGym \citep{Notin2023}, so that each fold is one residue class holding 836 to 874 variants. All mutations at one position therefore fall in the same fold, and a model cannot learn a per-position effect and look it up at test time \citep{Vieira2026}. The nanobody and humanness sets are grouped by single-linkage clusters at 95\% sequence identity, after \citet{Kenlay2024}, and the identity measure, the cluster sizes and the humanness labels are given in Appendix~\ref{app:datasets}. The trastuzumab variants differ from the wild type only in the ten residues of CDR-H3 and are grouped by how many of those residues are mutated. A held-out fold therefore contains variants at mutation counts not seen in training.

% TODO: review, needs manual review
The two nucleotide tasks come from the revised Nucleotide Transformer benchmark \citep{DallaTorre2025}. Both are grouped by chromosome, so each held-out fold contains between two and six of the 23 chromosome groups, none of which the model saw in training. Appendix~\ref{app:datasets} gives the task definitions and describes how the released files are regrouped.

% TODO: review, needs manual review
The TCGA datasets use RNA sequencing (RNA-seq) expression and other measurements of primary tumors, one sample per patient, obtained through UCSC Xena \citep{Goldman2020}. Samples are grouped by tissue source site, the institution that supplied the sample, which is read from the TCGA barcode. A model therefore cannot score well by recognizing the site a sample came from, and no patient appears in both the training and the test set.

% TODO: review, needs manual review
\paragraph{Consequences of the grouping.} Group definitions differ between domains by design, and the one rule they share is that no group spans training and test. Some groupings leave few or very unequal groups, and the folds inherit this imbalance. The trastuzumab held-out folds range from 13 to 3,035 variants, with binder shares from 15.5\% to 92.3\% against 32.8\% overall, and the breast cancer folds range from 3 to 403 tumors. None of the 68 lung sites supplied both tumor types, so the lung folds are unbalanced, with one fold holding 20 adenocarcinomas and 113 squamous tumors. The Koenig folds are fixed by the five groups of that dataset. Per-fold scores on these datasets spread more widely, so results are read per dataset, in the dataset's own metric, and never pooled across datasets.
\subsection{Representations by domain}
% [notes moved to thesis_notes_moved.md]
% TODO: review, needs manual review

We combine a variety of component, or base, representations to create these hybrids.

Any representation that gives one fixed-length vector per sample can serve as a base representation, as set out in the description of how the hybrid is built earlier in this chapter. The first version of the method used three molecular representations: PDV, ECFP4 and MHG-GNN. These three are now one small-molecule example among many. Every base representation is frozen: it is computed once from the raw input (a SMILES string, a sequence, a reaction or a patient profile) and is never trained on the labels.

For every data set in this study, we pre-selected ten base representations that spanned across different domains of information and showed some positive results when used on their own for the given prediction task.
% TODO: REVIEW MODIFICATION
For every dataset in this study, we pre-selected at most ten base representations that span different domains of information, each of which showed some positive results on its own for the given prediction task.

To choose them, every candidate representation was first scored on its own with a gradient-boosted tree model \citep{ke2017lightgbm} under the dataset's grouped folds. Candidates were then compared by the Spearman correlation between their out-of-fold predictions, since two representations whose predictions correlate highly carry much the same signal. At most ten were then chosen by hand, looking at each candidate's own score next to these correlations and favoring representations that encode the input in different ways. Two nucleotide datasets have fewer. H3K4me3 had 12 candidates, and four of them predicted almost the same as a better-scoring candidate, with a Spearman correlation of 0.95 or above between their out-of-fold predictions; eight remain. TATA promoter had 10 candidates, one was dropped by the same rule, and nine remain. Augmentation features do not count toward the ten. They are added after the hybrid is built (see the Augmentation subsection above), and the same representation can be a base representation on one dataset and augmentation on another.

If an input cannot be parsed or embedded, it gets an all-zero row, so that every representation of a dataset keeps the same rows. In computed descriptors, a missing or infinite value is set to 0, and values are stored unscaled. A pretrained model gives one vector per input, the mean of its last-layer token vectors with padding excluded, unless the tables say otherwise. Scaling and filling of missing values happen inside each fold, on the training rows only, as described in the construction of the hybrid.

\paragraph{Small molecules.} The small-molecule representations (Table~\ref{tab:reps_smallmol}) are the fingerprint, descriptor, graph and language-model families described in Chapter~\ref{chap:background}. The only additions are four sets of 3D shape and pharmacophore features, used as augmentation only. All four are computed from a single conformer per molecule, embedded with a fixed seed and optimized with the Merck molecular force field. A single conformer may misdescribe flexible molecules.

\paragraph{Chemical reactions.} Reaction datasets (Table~\ref{tab:reps_reactions}) use three kinds of representation. The condensed graph of reaction (CGR) merges reactants and products into one graph in which the bonds that change are marked \citep{Hoonakker2011}; here it is hashed into a circular fingerprint after atom mapping \citep{Schwaller2021rxnmapper}. Reaction language models read the reaction SMILES directly \citep{Schwaller2021rxnfp, Sagawa2023ReactionT5}. Any molecular representation can also be applied to the reactants, to the product, or to their difference. A one-hot encoding of which aryl halide, ligand, base and additive was used carries no chemistry. It is kept because on plate data such identity features can predict yield about as well as chemical descriptors \citep{Chuang2018}.

\paragraph{Antibodies.} Antibody representations (Table~\ref{tab:reps_antibodies}) start from the heavy- and light-chain amino-acid sequences. Besides one-hot and BLOSUM62 encodings \citep{Henikoff1992}, most are frozen language models, either trained on all proteins or on antibody repertoires only. Most models embed each chain separately and join the two vectors, so their width doubles on datasets with both chains. Several representations read one model in different ways, for instance averaging over earlier layers or over the CDR residues only, with CDRs found by IMGT numbering \citep{Lefranc2003} using ANARCI \citep{Dunbar2016ANARCI}. Datasets of point variants of one parent antibody also use features that describe each mutation.

\paragraph{Nucleotide sequences.} A $k$-mer frequency vector counts how often each DNA word of length $k$ occurs in a sequence, divided by the total number of words \citep{Vinga2003}; the canonical variant merges each word with its reverse complement \citep{Teeling2004}. DNA language models are networks pretrained on genomes to predict masked or next tokens \citep{Zhou2023DNABERT2, DallaTorre2025, Nguyen2023HyenaDNA}. Table~\ref{tab:reps_nucleotides} lists both kinds, along with the small sequence summaries used as augmentation.

\paragraph{Cancer patients.} For the two TCGA datasets (Table~\ref{tab:reps_tcga}), each representation is a different measurement of the same patient's tumor, not a different encoding of one input. The measurements are RNA-seq gene expression (read through foundation models or summarized per chromosome arm), DNA methylation on the HM450 array, gene-level copy number, microRNA abundance, protein levels from reverse-phase protein arrays, and embeddings of the diagnostic whole-slide image. Data were obtained from TCGA through UCSC Xena \citep{TCGA2013, Goldman2020}. The most-variable selections, the z-scoring and the principal components for methylation, copy number, microRNA and protein were fitted once on all patients in a cohort, held-out patients included. No labels are used in these steps. A patient with no measurement for one data type gets an all-zero row for that representation.

% CODE INPUT
The five downstream models cover bagged trees (random forest), boosted trees (XGBoost and LightGBM), a kernel method (SVM) and a neural network (DNN). Several models are used because the best set of features depends on the model that uses it. A hybrid that helped only one model family would reflect a property of that model rather than a better input. Tree ensembles are the baseline to beat, because a hybrid is a tabular feature matrix and tree-based models still lead on medium-sized tabular data of about 10,000 samples \citep{Grinsztajn2022}. A Gaussian process \citep{Rasmussen2006} is added as a sixth model on datasets under 1,000 molecules. Three of the 16 datasets are that small: humanness (564 sequences), nanobody thermostability (672 sequences) and breast cancer PAM50 subtype (821 tumors). In practice the Gaussian process runs on humanness only, and because humanness is a classification task, the Gaussian process there uses an RBF kernel. The regression version, with an RBF kernel plus a white-noise term, runs on none of the 16 datasets. PAM50 subtype is left out under every augmentation setting because of run time. In the search with augmentation features added beyond the budget, the Gaussian process took 44 of its 60 hours. Nanobody thermostability is left out under augmentation beyond the budget, where its searches did not finish within the time limit. Because a dataset that drops the Gaussian process under any setting receives it under none, nanobody thermostability is left out everywhere.

Every model uses the same settings on every dataset, so that differences between scores come from the input, and no per-dataset tuning is done by default. An optional per-fold random search tries 20 draws of a model's settings, each scored in the dataset's own metric on 3 group-aware inner folds of the outer training fold only. The DNN is never tuned in this way and relies on early stopping instead. \textbf{[RESULT NEEDED: whether tuning pays on base representations, tuned against untuned models, in each dataset's metric]}. Two models are skipped above a cap on the number of molecules. The Gaussian process is skipped above 1,000 molecules, because it builds and factorizes the full molecule-by-molecule kernel matrix. The SVM is skipped above 10,000 molecules, since beyond that size its kernel cache no longer holds the support vectors and a fit no longer finishes in useful time. Under augmentation beyond the budget, the SVM is skipped above 5,000 molecules. The caps count the molecules the search is given, which is the whole dataset for the search run once per dataset. A search inside one outer fold is given the training molecules of that fold, about 80\% of the dataset. On two datasets the two counts give different downstream models, in both cases under augmentation beyond the budget. LogD has 5,028 molecules and TATA promoter 5,274, so the SVM is dropped when the whole dataset is counted and kept when the roughly 4,000 training molecules of a fold are counted. Some default models are also not run on named datasets where a single fit was too slow, and these are listed in Additional file~\ref{app:add:models_left_out}. The settings, library, molecule cap and citation of every downstream model are given in Table~\ref{tab:add:model_settings} (Additional files).

The kNN model is not a default downstream model. Where it is used, it takes $k = 5$ neighbors by default, lowered to the square root of the number of training molecules when a fold has fewer than 25. It is the model used to compare importance-weighted with unweighted distances, a comparison that uses 5, 10 and 20 neighbors. Its settings are stated here because Chapter~\ref{chap:discussion}, ``Simple is often better'', relies on that result.

% CODE INPUT
Each dataset is scored in the metric its field normally uses, so that its numbers can be compared with published work on the same dataset. Small-molecule, quantum-chemistry and reaction-yield regression use RMSE, which is in the units of the label. Antibody regression uses Spearman $\rho$, because these assays are used to rank candidates and their scales differ between laboratories. Binary classification uses AUROC, which does not depend on a decision threshold. The two nucleotide datasets are the exception and use MCC, which is high only when all four entries of the confusion matrix are good \citep{Chicco2020}. The four PAM50 subtypes, whose class sizes range from 67 to 421 tumors, are scored with support-weighted F1. Table~\ref{tab:datasets} gives the metric of each dataset, and the definitions are given in Chapter~\ref{chap:background}, ``Evaluation methodology''. Each hybrid is paired by fold with the best single representation on the same fold. We use no significance tests and no confidence intervals, within or across datasets, because with 5 folds a $p$-value or an interval would rest on 5 correlated values. The fold scores are correlated because the folds share training molecules. No unbiased estimator of the variance of $k$-fold cross-validation exists, and estimates that ignore the overlap underestimate it \citep{Bengio2004}.

\subsection{Comparators, controls and ablations}
% [notes moved to thesis_notes_moved.md]
% - TODO(lit): read the Turkina2025 methods for whether high-level fusion pools the predictions of one model per fingerprint, as the ensemble here does.

% CODE INPUT
The hybrid is the best of many configurations, each a combination of allocation method, importance method, internal evaluator and budget, so its gain may be no more than the reward for a large search. The experiments below address this and related questions, one question each. They test whether the search overfits and whether a larger search helps, compare fusing features with fusing predictions and with standard feature reduction, and ask whether the internal evaluator must match the downstream model. Further experiments measure the stability of the selected features across folds, the change in gain with dataset size and the effect of using importance during training. The last three add a few features to one representation, test robustness to label noise and join two whole representations. All of them use the group folds of ``Datasets and splitting''.

% CODE INPUT
The hybrid's score is the best of many configurations, whereas each single representation gives one score, and the best of many cross-validated scores is biased upward \citep{Varma2006}. Several experiments therefore use leave-one-fold-out reselection, in which, for held-out fold $f$, we pick the hybrid configuration with the best mean score on the other folds,
\[
c^*_{-f} = \arg\max_c \frac{1}{F-1}\sum_{g\neq f} s_{c,g},
\]
where $s_{c,g}$ is the score of configuration $c$ on fold $g$ and $F$ is the number of folds (arg min for RMSE). The best single representation, $k^*_{-f}$, is picked in the same way, and we then report
\[
\Delta_f = s_{c^*_{-f},f} - s_{k^*_{-f},f},
\]
signed so that $\Delta_f>0$ means the hybrid is better (for RMSE the sign is flipped). Because this is arithmetic on stored per-fold scores, it needs no extra model fits. Importance scores and the feature selection are always recomputed on the training molecules of each fold only. Some experiments, however, choose the configuration by a search over all molecules and redo only the feature selection per fold. Their scores are therefore not fully held out, and we say so where this applies.

% CODE INPUT
The first experiment uses nested cross-validation to ask whether the search overfits as the budget grows. For every budget $B$, the winning configuration at that budget is rebuilt on the outer training molecules and scored on the outer held-out fold. The selection bias at a budget is the score reported by the inner search minus the held-out score, signed so that a positive value means the search promised more than the held-out fold gave. The budgets are the standard list from 10 to 2,000 features, plus 4,000 and 8,000 features. To these we add budgets at 0.5, 0.75, 1, 1.25, 1.5 and 2 times the smallest outer-fold training-set size in molecules, which place a budget where the number of features equals the number of molecules. For the five downstream models, the budget does not set the number of fitted parameters. The DNN and the random forest have more fitted parameters than training molecules at every budget. The SVM is fitted with at most one coefficient per training molecule, so it never can, and the capacity of the boosted trees is set by the number and depth of their trees. For these five models, the curves therefore show whether the search's choice of budget overfits. The experiment adds one model outside the five, a linear model with almost no penalty, either ridge regression with penalty $10^{-6}$, or logistic regression with $C = 10^{6}$ for classification. This model has one weight per selected feature, so its parameter count equals the budget. We report two numbers per model, the budget picked by the search of each outer fold and the budget with the best held-out score. A pick far above the best held-out budget indicates that the search overfits. \textbf{[RESULT NEEDED: held-out score and selection bias against budget, per model and dataset]}.

The size of a search is the number of configurations it scores, that is, the product of the numbers of budgets, allocation methods, importance methods, internal evaluators and representation counts. At the full tier this gives 480 configurations for each pair of downstream model and internal evaluator, and at the fast tier 48 (Additional file~\ref{app:add:search_size}). The question is whether the hybrid's lead over each comparator grows with the number of configurations. The comparators, namely the ensemble, the best single representation, PCA and feature reduction at the same width, receive no search. Part of any gap that grows with search size therefore reflects the hybrid taking the best of more draws. Leave-one-fold-out reselection charges the hybrid for this, and we report the reselected numbers. In the full runs each dataset is searched at one tier only, full or fast, whereas a search-size comparison needs the same dataset searched at two sizes. \textbf{[RESULT NEEDED: hybrid minus each comparator, per dataset, at each search size]}.

% CODE INPUT
The ensemble fits one model per representation and pools their predictions, whereas the hybrid fits one model on one fused feature vector. Joining features before a single model is early fusion, and pooling the predictions of one model per feature set is late fusion \citep{Stahlschmidt2022}. The hybrid runs its own search on the training molecules of each outer fold. Every choice for the ensemble is made on an inner 3-fold group split of the same training molecules, so the held-out fold is used once. The ensemble either fits the same model on every representation or lets each representation use its own best model. Its members are either the top 3 representations or every representation with at least 50 features. The predictions are pooled in one of seven ways. Three are the mean, the median and a 20\% trimmed mean, and two are means after removing outliers found by interquartile range or by median absolute deviation. The last two are a mean weighted by the inner score of each member and the mean of the top 3 members. Classification ensembles pool predicted probabilities, and where the metric reads class labels, a majority vote is also offered. Three controls are included in the comparison. The first is the best single representation, and the second joins all representations and reduces them by PCA to the width of the hybrid. The third is the best pair of model and representation read off the held-out fold, which serves as an upper bound rather than as a fair comparator. Beside each score we report the cost as the number of representations computed at prediction time, the number of models deployed, and the fit and prediction time in seconds. The hybrid saves cost only if it draws on fewer representations than the ensemble. Because an ensemble is the obvious simpler alternative, a result in which it matches the hybrid at lower cost belongs in Chapter~\ref{chap:discussion}, ``Simple is often better''. In QSAR, \citet{Turkina2025} combined six non-hashed fingerprints by low-, mid- and high-level fusion on six regression and classification datasets. Mid-level fusion, which keeps fingerprint bits by their importance in the per-fingerprint models, gave the best accuracy. \textbf{[RESULT NEEDED: held-out score and cost per method]}.

The next experiment asks whether the gain comes from drawing on several representations or only from having fewer features. Every method receives the same number of features, $B$, drawn from all base representations and fitted on the training molecules of the fold, and the experiment runs on regression datasets only. The methods are the hybrid, PCA, mRMR \citep{Peng2005}, recursive feature elimination \citep{Guyon2002} and $B$ features drawn at random. The hybrid uses its stored configuration at budget $B$, with the features re-selected on each fold. For PCA, all base representations are joined and each feature is z-scored on the training molecules of the fold. PCA is then fitted on those molecules with $B$ components, capped at the total number of features and at one fewer than the number of training molecules. Held-out molecules are projected with the fitted PCA, and the PCA control of the ensemble comparison is built in the same way. The mRMR ranking stops at 200 features for run time. When the representations hold more than 2,000 features in total, mRMR first keeps the 2,000 with the highest mutual information with the label. Recursive feature elimination uses a random forest of 50 trees of depth at most 5. A single downstream model, a random forest of 100 trees, scores every method, so only the features differ. This comparison is not fully held out, because the configuration of the hybrid is chosen using all molecules and only its feature selection is redone per fold. \textbf{[RESULT NEEDED: held-out score against $B$ (features) for each method]}.

The search scores each representation with an internal evaluator to split the budget, and the winning hybrid then goes to a downstream model. This experiment asks whether the two must match. As in the overfitting experiment, it uses nested cross-validation, with one search per outer fold for each evaluator setting, and each setting is compared with the matched evaluator. The matched evaluator belongs to the same model family as the downstream model and uses the lighter evaluator settings of Table~\ref{tab:add:model_settings}. The near-family setting scores the random forest with LightGBM and the reverse, and XGBoost with LightGBM. It also scores the SVM with a Gaussian process, and the DNN with a narrower DNN of 64 and 32 units. The far-family setting scores the three tree models with an SVM, the SVM with LightGBM, and the DNN with $k$-nearest neighbors. A fourth setting scores the DNN with a wider DNN of 512, 256 and 128 units. The last setting uses a fixed set of three evaluators (random forest, LightGBM and XGBoost) and keeps the best. We report each setting minus the matched evaluator, paired per outer fold, at the same number of features. Evaluators with the exact settings of the downstream random forest and LightGBM are implemented, but no search uses them, so the full runs do not report them. The answer determines whether one cheap evaluator is enough or whether the search must be rerun for each model. \textbf{[RESULT NEEDED: each setting minus matched, per downstream model]}.

% CODE INPUT
Selection on each of the $M$ folds gives a binary vector $\mathbf{z}_m \in \{0,1\}^d$, where $d$ is the number of features in all base representations joined. We measure the stability of the selection with the index of \citet{Nogueira2018},
\[
\hat\Phi = 1 - \frac{\frac1d\sum_{f=1}^d s_f^2}{\frac{\bar k}{d}\left(1-\frac{\bar k}{d}\right)}, \qquad s_f^2 = \frac{M}{M-1}\hat p_f(1-\hat p_f).
\]
Here $\hat p_f$ is the fraction of folds that selected feature $f$, and $\bar k$ is the mean number of features selected. A value of $\hat\Phi=1$ means that the same features were chosen on every fold, and $\hat\Phi \approx 0$ is what random selection gives. The width $d$ must be the full number of features in all base representations joined, rather than the size of the union of the selected features. Unstable feature sets would weaken any chemical reading of the blueprints. \textbf{[RESULT NEEDED: $\hat\Phi$ per dataset and model]}.

The learning curves draw subsamples of 10, 25, 50, 75 and 100\% of the molecules as whole groups, never with fewer than 50 molecules. Above 5,000 molecules, absolute sizes of 250, 500, 1,000 and 2,000 molecules are used instead. Each size is drawn 3 times, except the 100\% point, which is drawn once because every draw is the same. A full search runs on each subsample, with budgets above the number of training molecules dropped. The gain at each size is the hybrid minus the best single representation, with leave-one-fold-out reselection. Because small subsamples search fewer budgets, part of any rise in gain with size may come from searching more configurations. \textbf{[RESULT NEEDED: gain per dataset, model and size]}.

% CODE INPUT
This experiment asks whether importance also helps during training, in addition to its use in selection. It uses the hybrid at 100 features with random forest, LightGBM and XGBoost, the three models that accept per-molecule weights. Importance is computed on the training molecules with the importance method the search picked for that hybrid. The experiment compares the following five conditions:
\begin{enumerate}[leftmargin=*]
    \item No weighting, in which the hybrid is used as selected.
    \item Feature weighting, in which features are multiplied by the square root of their importance after standardizing, with the weights normalized to average 1.
    \item Molecule weighting, in which molecules are weighted by how well their label agrees with their 10 nearest neighbors in the rescaled space.
    \item Combined weighting, which applies feature weighting and molecule weighting together.
    \item Above-median selection, which keeps only the features strictly above the median importance.
\end{enumerate}
The weight of molecule $i$ is $1 - |y_i - \bar y_{N(i)}| / (\max y - \min y)$, clipped to lie between 0.1 and 1. Here $\bar y_{N(i)}$ is the mean label of its 10 nearest neighbors by Manhattan distance. This comparison is not fully held out, because the configuration comes from a search over all molecules and only the feature selection is redone per fold. Molecule weighting is a noise-mitigation method that down-weights suspect labels. Tree ensembles are unchanged when a feature is multiplied by a positive constant, because their splits depend only on the order of values \citep{Hastie2009}. Feature weighting therefore differs from no weighting in one respect only. Features with zero importance receive weight zero, become constant and drop out, while every other feature is only rescaled, which the three tree models ignore. The rescaling does matter for molecule weighting, because it changes which molecules are nearest neighbors. Checking a label against its nearest neighbors goes back to the editing of a training set by its nearest neighbors \citep{Wilson1972}, although here the molecule is down-weighted rather than removed. We found no QSAR study that down-weights training molecules whose labels disagree with their nearest neighbors. The nearest prior work lies outside QSAR, where nearest-neighbor noise filters adapted to regression labels remove such samples instead of down-weighting them \citep{Martin2021}. Learned per-sample training weights for noisy labels come from general machine learning \citep{shu2019metaweightnet}. \textbf{[RESULT NEEDED: one result line]}.

This experiment asks whether a few extra features help one strong single representation. Two kinds of decoy are planted among the candidate features. The first is a block of pure Gaussian noise as wide as the real candidate features combined. The second consists of near-copies of 64 base features with added noise at 5\% of the standard deviation of each feature. We count how many decoy features are taken on each fold, and a working rule takes none of them. The same extra features are also offered to the hybrid built from several representations, to ask whether extra features do more for one representation or for the hybrid. \textbf{[RESULT NEEDED: one result line, with the decoy features taken per fold]}.

% CODE INPUT
This experiment asks whether hybrids are more robust to label noise than their base representations. Robustness is measured by \aucnorm, the normalized area under the retention curve of Chapter~\ref{chap:robustness} (Equation~\ref{eq:auc_norm}). The setup differs from that of Chapter~\ref{chap:robustness} in two ways. First, the retention curve uses each dataset's own metric instead of $R^2$, with the ratio inverted for an error metric so that 1 still means no loss. Second, there are seven noise levels, 0, 0.2, 0.3, 0.5, 0.75, 1.0 and 1.5, each a fraction of the spread of the clean training labels of the fold. Censoring has its own axis, the fraction of labels clipped, with values of 0, 0.10, 0.20, 0.25, 0.30 and 0.40. We compare the hybrid at each budget with each single representation and with the best single representation, re-picked in each fold. One downstream model, a random forest, is used under each regression noise type. The settings of the hybrid are searched again at every noise type and level on the noisy training labels, while the held-out labels stay clean. Because the search uses the scores of the first fold to drop configurations, that fold is left out of both sides and four folds are reported. In Chapter~\ref{chap:robustness} most of the variance in \aucnorm was explained by the model rather than by the representation, whereas here the model is fixed, so only the representation changes.

The last experiment asks whether joining two whole representations scores above the better of the two or between them. Three further studies go beyond the single-dataset setting by reusing search settings on a second dataset, building hybrids on antibody mutational scans, and selecting features with data held at separate sites. Each needs several numeric representations of the same objects, one supervised target, and a grouped split that keeps near-duplicates on one side. For each study we give a short background and describe how the setup was built and scored, and the outcomes are reported in the results sections.

% CODE INPUT
The first study asks whether search settings found on a large dataset can be reused on a small one instead of running a new search. These settings, namely the importance method, the allocation method, the budget $B$ and the internal evaluator, are decisions about the search rather than a set of features. The source dataset is LogD (lipophilicity), with 5,028 molecules, and the target dataset is hERG binding affinity ($\mathrm{p}K_i$), with 1,412 molecules. The candidate representations are those listed for both datasets, kept only where the width (number of features) matches, so that both searches range over the same features. The current lists share seven representations, namely Avalon, ECFP4, Mordred and four pretrained embeddings (GROVER, MHG-GNN, SMI-TED and ChemBERT), although the width check can still drop some of them. \textbf{[RESULT NEEDED: the shared representation set the full run uses]}. Because the search is the expensive step, settings that transfer would make it a one-off cost, paid on the largest dataset. The closest prior work is Meta-QSAR \citep{Olier2018}, which chose the learning method and molecular representation for a new QSAR dataset from results on over 2,700 other QSAR datasets. It beat random forest on a fingerprint by up to 13\% on average and, like the source search settings here, reuses decisions rather than a set of selected features. We have not found a paper that applies feature indices selected on one QSAR dataset unchanged to another, although our search of the literature was not complete.

% CODE INPUT
All four comparisons run inside every held-out fold of the target. The first is the best single representation, re-chosen on the training molecules of that fold, and the second is a hybrid searched on the same training molecules, which serves as the upper reference. The third applies the source search settings with the features re-selected on the training molecules of the target. The fourth applies the source's own selected feature indices unchanged, so that no target label is used to pick features. The last two separate two questions, whether the search decisions transfer and whether the chosen features transfer. We use five scaffold-group folds, RMSE in $\mathrm{p}K_i$ units and the five downstream models (random forest, LightGBM, XGBoost, SVM and DNN). \textbf{[RESULT NEEDED: hybrid minus best single representation for each transfer comparison, per downstream model]}.

% CODE INPUT
A deep mutational scan measures a property, here expression or binding, for many single- or few-point mutants of one antibody, and is used to map which positions tolerate change. We use four scans with a single wild type, taken from FLAb \citep{Chungyoun2024}. Two are the expression and binding scans of the anti-VEGF antibody G6 \citep{Koenig2017}, of which the expression scan is one of the 16 datasets of this chapter. The other two are the expression and binding scans of the anti-fluorescein antibody 4-4-20. The candidate representations are the protein language-model embeddings and the cheaper sequence features of ``Representations by domain'', to which we add two representations of the change from the wild type. The first has 5 features, the changes in hydrophobicity, charge, isoelectric point, molecular weight and aromaticity summed over the mutations, with each property first z-scored over the 20 amino acids. The second places the same five features at the mutated position, so it has five features for every sequence position. Under nested cross-validation, the search sees the outer training variants only, and the hybrid and every single representation are scored on the untouched outer fold. The continuous scans are scored by Spearman correlation. The 4-4-20 binding scan is binarized, with a variant counted as a binder if its $\mathrm{p}K_d$ is above 5.0, and scored by AUROC. We report the hybrid minus the best single representation, per scan, on the outer folds. The two wild-type-difference representations are also scored as single representations, and each run reports their rank among all representations. The number of features each representation received is stored per fold with every result, but this comparison does not report it. Without that count, the difference between the hybrid and the best single representation says nothing about the wild-type-difference representations. \textbf{[RESULT NEEDED: features the hybrid took from each of the two wild-type-difference representations, per scan, per fold]}. \textbf{[RESULT NEEDED: hybrid minus best single representation per scan, per downstream model]}.

% CODE INPUT
Federated learning trains one model across data held by several parties without moving the data \citep{McMahan2017}, and it has been run across pharmaceutical companies on shared property-prediction targets \citep{Heyndrickx2024}. In this field the motivation is commercial, because structures and assay results are the asset and pooling them is therefore not possible \citep{Hanser2023,Bassani2023}. Our collaborator, Lhasa Limited, uses the teacher-student process described in Chapter~\ref{chap:background}, ``Noise in molecular data'' \citep{Hanser2025}. We use the collaborator's code for the fingerprints, the site models and the site clustering, so that the numbers stay comparable to theirs. The step that combines the predictions of the site models is re-implemented from that code.

% CODE INPUT
The predictions of the site models are combined in one of two ways. Under distance weighting, the vote of each site model on a molecule is weighted by how close that molecule is to the site's own training molecules. A site therefore counts most on chemistry it has seen. Closeness is the mean fingerprint distance from the query molecule to its 8 nearest neighbors among a random 20\% of the site's training molecules. The distance is set per run and is Manhattan by default, whereas the collaborator's code uses Euclidean distance. For each site, these distances are rescaled to the range 0 to 1 over the query molecules. Each is turned into a similarity as $(1 - \text{distance})^2$, and the similarities are normalized to sum to 1 over the sites. Under score weighting, each site instead receives a single weight from its own cross-validated MCC. Only predictions on shared molecules cross a site boundary. In the published process, a student model is then trained on the most confident combined labels, with the same number from each class. In the hERG comparison below, no student is trained, and the combined predictions score the held-out molecules directly.

% CODE INPUT
The addition made in this thesis is that feature selection, as well as model fitting, takes place at the sites. Each site runs the hybrid search on its own molecules, choosing features on 80\% of them and scoring them on the other 20\%, split by scaffold group. Each site reports three things, namely feature indices, importance values and one score, and no molecule or feature value leaves the site. A coordinator splits the total budget $B$ across sites in proportion to their scores, rounding each share $b_s$ down with at least one feature per site, so that $\sum_s b_s \approx B$. If every site scores 0, the budget is split equally. Only the proportional split is run, so without an equal-split comparison we cannot say what the site scores buy. A feature that another site has already taken is skipped, and the site takes its next-ranked feature instead, so the features in the hybrid are all distinct. Indices and importances are smaller, and harder to invert, than model weights or gradients. Splitting the budget between sites is also the same question that the allocation method answers between representations. In related work, each client runs a mutual-information feature selection on its own data and a server aggregates the results, with no raw data exchanged \citep{Cassara2022}.

% CODE INPUT
hERG channel blockade is a cardiotoxicity liability screened early in drug discovery, and its public data come from many laboratories \citep{Czodrowski2013}. Three real sources act as sites, namely the public ChEMBL hERG $K_i$ set used elsewhere in this thesis and the collaborator's training set (7,772 molecules) and test set (4,383 molecules). The two collaborator sets were labeled by different curation rules, so the sites differ in curation as well as in chemistry. This source heterogeneity exists in practice, whereas the process is usually simulated with sites made by clustering one dataset. Molecules held by more than one source are deduplicated on InChIKey, keeping the public copy. The target of the public set is binary, with a molecule counted as a blocker if $\mathrm{p}K_i \ge 6$, that is, $K_i \le 1\,\mu\mathrm{M}$. We use five scaffold-group folds over the pooled molecules, and the search is scored by AUROC. The reported number is MCC, which does not reward predicting the majority class.

% CODE INPUT
The comparison crosses two choices, whether molecules are pooled or kept at their sites, and whether all features or a selected set are used. Pooled molecules with all features form the upper reference, which is not possible in practice. Pooled molecules with selected features measure what the selection is worth on its own, and molecules at their sites with all features correspond to federated training as usually done. Molecules at their sites with selected features form the only setting in which nothing but indices, importances, one score and predictions moves between sites. The difference between selected and all features at fixed site structure is what selection buys, and the difference between pooled and site-held molecules at fixed features is what pooling buys. We add four context comparisons, namely the single best source picked on training molecules, both ways of weighting the site models, the same search on one fingerprint alone, and one site model per representation. The budget $B$ is swept over 50, 100, 250, 500 and 1,000 features, so that no comparison rests on one width. Both all-features settings fit one 2,048-bit Morgan fingerprint of radius 2 with pharmacophoric atom types. Both selected settings instead fit features drawn from the candidate representations of the hERG $K_i$ dataset. Selected minus all features therefore differs in two ways at once, in width and in source. The budget sweep varies only the width of the selected set and cannot separate the source difference. The closest control for the source difference is the single-fingerprint search, which is the same search run on ECFP4 only. Two curators disagreeing on one molecule constitute label noise with a known source (Chapter~\ref{chap:similarity}).

% CODE INPUT
Four further separate-site experiments are run. In the first, the sites carry different amounts of label noise. Selection at the sites is compared, at several noise levels, with the ensembles of site models and with one model trained on the pooled molecules of all sites. In one version of this experiment, each site first removes the molecules it flags as noisy. In the second, every site holds the same molecules as a different representation, and fusing features is compared with pooling the predictions of the site models. In the third, the sites hold different families of representations (substructure, physicochemical and pretrained) of shared molecules. In the fourth, the sites are three antibody sources, namely a binding-energy-change set, a deep mutational scan of binding and a thermostability set. Sub-sites within a site are made by clustering language-model embeddings instead of fingerprints. The antibody version skips the two ensemble comparisons. Each site's features are reduced separately, so one site's model cannot predict on another site's features, and the labels are in incompatible units (kcal/mol, a normalized score and degrees Celsius). \textbf{[RESULT NEEDED: one line on the outcome of each of the four]}.

% CODE INPUT
The separate-site work has four limitations. One source is proprietary and cannot be redistributed, so the comparison cannot be reproduced from public data alone (Appendix~\ref{app:availability}). The comparison also depends on the collaborator's implementation of the process. The published process labels a large separate public set and trains a student on it. Where a student is trained here, the training molecules play that role as a compromise, and held-out molecules are excluded from it. Finally, the sites differ in size and in how their labels were derived, so a site's score reflects its curation as well as its chemistry.

Three external benchmark tasks that are not among the current datasets are possible later additions and are not run here. The first is activity-cliff prediction on the dopamine D2 receptor, factor Xa and SARS-CoV-2 main protease, following a published comparison of representations and models \citep{Dablander2023}. The second is antibody developability, on the biophysical properties of a public competition set, using that competition's cluster splits \citep{vanNiekerk2026}. The third is antibody--antigen binding free-energy change, asking how close sequence representations get to a structure-based graph network \citep{Hummer2025}.

\section{Discussion}
% [notes moved to thesis_notes_moved.md]
% - TODO(lit): neither source above is a study of when combining gives no gain. A source that reports it directly is still needed.

% TODO: review, needs manual review
Ambroise and McLachlan \citep{Ambroise2002} showed the extreme case of overfitting through feature selection. An SVM achieved near-zero cross-validated error on random labels when genes were selected on the full dataset before cross-validation. When selection was nested inside each fold, the median error was 11 out of 40, close to the 50\% expected by chance. Vabalas et al.\ \citep{Vabalas2019} showed that the bias introduced by pre-selection can exceed the bias from hyperparameter tuning. Cawley and Talbot \citep{Cawley2010} argued that feature selection is itself a form of model selection whose complexity cost must be accounted for. The hybrid search follows the standard remedy of computing all importance scores within each cross-validation fold, on training data only. The problem of search degrees of freedom \citep{Tibshirani2015} nevertheless remains, since searching over many possible feature subsets adds complexity even when each individual selection is unbiased. The budget acts as a hard capacity constraint. Selecting 100 features from a pool of 5,000 limits the space of possible selections far more tightly than $L_1$ regularization over the same pool. The reason is that the feasible set grows polynomially in the budget while the continuous parameter space of a regularized model is unbounded \citep{Ng2004}. The features being selected are, moreover, frozen embeddings rather than parameters being fitted. We consider choosing which pre-existing knowledge to trust a less expressive operation than learning new features. In support of this view, Kumar et al.\ \citep{Kumar2022} showed that frozen embeddings fed through a linear probe can outperform full fine-tuning by up to 10\% in out-of-distribution accuracy, because fine-tuning distorts pretrained structure. Finally, stability can be measured directly with the Nogueira index \citep{Nogueira2018}, which quantifies the consistency of selected feature sets between folds. If selection were overfit, the selected feature sets would differ widely from fold to fold.

\section{Limitations}

The adaptive hybrid representation has several limitations. For small datasets, below about 200 samples, the hybrid search cannot reliably outperform the best single source. We suspect that this is because the internal validation set within each fold shrinks to roughly 20 samples, at which size the evaluator cannot distinguish genuine improvements from noise, and tuning cannot fix this. At the other extreme, frozen embeddings have a ceiling, since no signal can be added beyond what the inputs already contain. This ceiling binds on tasks where the true signal requires end-to-end learning from raw inputs, for example certain 3D quantum-mechanical properties, where SchNet outperforms any frozen embedding by a wide margin. The method naturally accommodates embeddings from sequence-trained models such as ESM-2 and ProtBERT. Encoding raw sequences directly as one-hot or $k$-mer features, however, disperses the positional and compositional information that makes sequences useful in the first place. Integrating 20 to 50 foundation models into a single pipeline, each with its own dependencies, GPU requirements and version constraints, is also difficult engineering. Embeddings need to be computed only once per dataset and are cached, but the initial integration burden is real and scales with the number of models in the pool. Finally, on endpoints with high experimental noise, even a well-constructed hybrid may not improve on simpler baselines. Kramer et al.\ \citep{Kramer2012} documented that the experimental uncertainty in heterogeneous public $K_i$ data is approximately 0.54 log units, which sets a natural accuracy ceiling of $R^2 \approx 0.81$ regardless of model sophistication. The budget constraint plausibly guards against overshoot, but it cannot push past this noise floor.
